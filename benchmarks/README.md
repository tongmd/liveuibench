# LiveUIBench dataset

The canonical release contains 319 cases: 147 development and 172 public test cases, with 230 initial-world fixtures. Sealed test cases are excluded.

See [protocol and commands](../docs/benchmarks/README.md), [provenance](provenance.json), and [integrity audit](../docs/audit/EXPERIMENT_AUDIT.md). Fixtures initialize simulator state; they are not generated app answers. Fixture contacts are not sent to the generator by default.
